Work with Linear issues from Kettu.

What you get
- Mention an issue: type @ in the message box and pick an issue. The agent reads its identifier, address, state, priority, team, assignee and description.
- References: a linear.app issue address in a reply is drawn as the issue, with its state, and shows its details when you point at it.
- Tools for agents: search issues, read an issue with its newest comments, create an issue, and comment on one. Kettu asks you before an agent uses them, as it does for any tool.
- A panel beside the session that lists your open issues, with a page for each issue.

Set it up
1. In Linear, open Settings > Security & access and create a personal API key. Creating issues and comments needs a key that may write.
2. Paste it under Settings > Plugins > Linear. Optionally enter the key of the team new issues go to when the agent names none, such as ENG.

What it may do
It may reach api.linear.app, with your key, and linear.app, whose addresses it needs to recognize in replies; it only sends your key to api.linear.app. It adds to a message only the issues you mention. It cannot run commands or read your files.

Keep in mind
- It sees what your key sees. Linear allows 2,500 requests an hour per user; cards for issues are kept for a minute so a long reply does not use many.
- Only issues of the workspace your key belongs to show as references.
